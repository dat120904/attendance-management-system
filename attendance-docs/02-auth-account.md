# 02. Dang nhap va tai khoan

## Chuc nang

- Dang nhap bang email/mat khau.
- Quen mat khau.
- Doi mat khau.
- Xem va cap nhat ho so ca nhan.
- Dang xuat.
- Quan ly phien dang nhap.
- Tuy chon 2FA neu doanh nghiep bat cau hinh bao mat nang cao.

## Trang can co

- Login.
- Forgot Password.
- Reset Password.
- My Profile.
- Change Password.

## Quyen truy cap

- Employee: dang nhap, dang xuat, xem/sua thong tin ca nhan duoc phep.
- Manager: nhu Employee.
- HR: nhu Employee, co the xem thong tin ho so nhan vien trong module nhan su.
- Payroll: nhu Employee, chi xem thong tin lien quan tinh cong/luong neu duoc cap.
- Admin: quan ly tai khoan, khoa/mo khoa, reset mat khau, cau hinh bao mat.

## Test can co

- Dang nhap thanh cong.
- Dang nhap sai mat khau.
- Tai khoan bi khoa khong dang nhap duoc.
- Quen mat khau tao token hop le.
- Reset password het han bi tu choi.
- Session timeout dung cau hinh.
- Logout xoa session/token.
