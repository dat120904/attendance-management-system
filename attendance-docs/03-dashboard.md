# 03. Dashboard

## Chuc nang

- Dashboard ca nhan cho Employee.
- Dashboard quan ly phong ban cho Manager.
- Dashboard HR/Admin toan cong ty.
- Dashboard Payroll theo ky cong.
- Canh bao di muon, thieu check-out, vuot gio, nghi phep sap toi.

## Widget chinh

- Current session.
- Hours this week.
- Remaining leave.
- Next holiday.
- Recent logs.
- Pending leave requests.
- Attendance exceptions.
- Payroll readiness.

## Quyen truy cap

- Employee: xem KPI ca nhan, check-in/check-out, log gan day.
- Manager: xem them tong quan nhom, danh sach nhan vien di muon/thieu cong.
- HR: xem tong quan toan cong ty, don nghi cho xu ly, log bat thuong.
- Payroll: xem so lieu lien quan ky cong va canh bao truoc khi tinh luong.
- Admin: xem tat ca widget va cau hinh widget.

## Test can co

- Dashboard hien dung theo role.
- KPI ca nhan tinh dung.
- Current session cap nhat khi check-in/check-out.
- Recent logs hien dung 4-5 ban ghi moi nhat.
- Nguoi khong co quyen khong thay dashboard phong ban/toan cong ty.
- Responsive desktop, tablet, mobile.
